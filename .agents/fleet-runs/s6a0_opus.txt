**How the fixed path runs:**
1. Next on a clean Identity step for a patient who isn't done (or a new patient) sets `awaitingAdvance` (`AncViewModel.kt:363-369`).
2. Because `patientDraft != null`, the ViewModel calls `savePatientProfile()`. Nothing in that function skips a clean draft.
3. `prepare` gets `forceAgeRequired = forcesAgeRequired()`, which is true at Identity. It rejects: a new patient has no stored age, and a legacy patient's age is forced to be required.
4. `PatientValidationFailed` puts the errors on the draft. The post-pass in `withFlowConsistent` clears `awaitingAdvance`, so the user can press Next again.
