Directory, chart and visit entry

Three live phones (about 360 dp wide, like an Honor 400). Same rules everywhere: one thing open at a time, closed rows read “Label value >”, the open row shows big one-tap choices, abnormal values turn rose but never block, the primary button is pinned. Every list of choices ends with + Add other: type a value, it is used at once and kept for later patients. All data is made up (patient Maya Example, today 1 Nov 2026 is 28w 0d). Nothing is saved. Use A- / A+ and Light / Dark in the bottom bar.

Laboratory, ultrasound, medication and the other approved screens: see the other pages (page 1, page 2).

1 · Patient directory

Find a patient in one glance. Only the risk badge carries colour; everything else is calm text. Try: type “fat”, tap the High chip, tap a card to open the chart, tap “⋯” on a card for Edit or Archive (then Undo).

What changes vs today

  • One colour: only the risk badge is coloured; no coloured left edges, no icon rows.
  • Clinical attention at a glance: the doctor's own short note (up to 140 characters) on at most two lines; edit it from the chart.
  • Labelled actions: a 48dp “⋯” opens a sheet with words (Edit, Archive), not tiny icons on every card.
  • Filter chips with counts sit under the search box; one pinned “New patient” button replaces the toolbar icon.

2 · Patient chart

One header that stays put (identity, GA, risk, alerts bell) and four tabs under it. The clinical attention line has an Edit action; Save updates the chart and the directory card. The visit list is a timeline whose vitals read on one line. Try: Edit the attention line, add quick phrases or your own, Save (then open the directory phone to see the card); switch tabs; tap the bell; tap “Add”.

What changes vs today

  • One sticky header replaces the stack of cards: name, age, G/P, blood group, GA pill, risk pill, bell with count.
  • Tabs Visits | Scans | Labs+Meds | Notes: nothing longer than a screen and a half.
  • Timeline: date, GA, “BP 118/76 · Wt 74.5 kg” on one line, then a short summary.
  • One “Add” button opens a sheet: Visit, Ultrasound, Lab, Medication, Note.
  • + Add other in the attention sheet: your own phrase is used now and offered next time.

3 · Visit and vitals entry

The most-used screen, so the fewest taps. Four steps; each step shows closed rows, one opens at a time, answering opens the next blank one. Try: step 1 “Same as last” then Next; step 3 “Fill normal values”; or type BP 150 / 95 and see it turn rose (it still saves).

What changes vs today

  • Date defaults to Today; BP is two big cells with “Same as last” and “Normal” chips.
  • Weight and fundal height start from the last visit; one tap repeats it.
  • “Fill normal values” fills only oedema none, movements good, urine negative, and only blanks. It never touches BP or weight.
  • BP 140/90 or higher turns rose with a flag; it never blocks saving.
  • + Add other ends the oedema, movement, urine, BP, weight and fundal-height choices: one line to type, “Saved for next time” with Undo.
  • Last step is a one-line summary, then a pinned “Save visit”.
