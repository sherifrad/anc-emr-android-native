**Should-fix**
1. **Second copy of the card look.** The More toggle is wrapped in a hand-written `Surface(shape = RoundedCornerShape(16.dp), border = BorderStroke(1.dp, ...outlineVariant.copy(alpha = 0.5f)), tonalElevation = 1.dp)` at `UltrasoundEditor.kt:579-594`. This duplicates the `SectionCard` look, which breaks the reuse rule and the spirit of U201. Use `SectionCard(title = "")` around the `SummaryRow`. That also lets you drop the `BorderStroke` import and the `Box` padding hack at line 586.
2. **The "next blank finding" rule is written twice.** `nextBlankFinding` takes four positional strings plus an `afterKey` and rebuilds a `mapOf` on every call. The 4-branch `when (finding.key)` at lines 379-385 repeats the same call four times only to substitute `choice`. It is also called from three more places (lines 117, 194 and 207). Take a map or the draft values plus an override, so `onSelected` is one call. This removes the `when`, the dead `else -> null` branch and the positional-argument swap risk.
3. **Text can run vertically at 160% font.** In `SummaryRow` (`DesignSystem.kt:87-93`) the label has `weight(1f, fill = false)` while the value `Text` (line 98) has no weight or `maxLines`. A long value such as an anterior or fundal placenta site, or a long label like "More: photos and visit link", shrinks the label to a narrow column. Give the value `Modifier.weight(1f, fill = false)` too, or let the row wrap.
