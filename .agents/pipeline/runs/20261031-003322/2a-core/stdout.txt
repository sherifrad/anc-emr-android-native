**Q68 / S50:**
- **New function:** I added a top-level `captureTempFile(cameraDir: File, expectedAuthority: String, scheme: String?, authority: String?, pathSegments: List<String>): File?`. It has no android types in its signature.
- **What it checks:** It returns the canonical file only when all of these hold:
  - the scheme is `content`;
  - the authority equals `expectedAuthority`;
  - there are at least two segments and the first is `camera_photos`;
  - the resolved candidate is a regular file whose parent is exactly `cameraDir.canonicalFile`.
- **Failure behaviour:** Any exception gives null. A `..` segment, a sub-folder, a segment containing a separator, or a symlink that resolves elsewhere all fail the parent check.
- **Thin wrapper:** `deleteIfCaptureTemp(context, uri)` now calls `captureTempFile(cameraDir(context), "${context.packageName}.fileprovider", uri.scheme, uri.authority, uri.pathSegments)?.delete() == true`. It no longer contains `canonicalFile`.
- **Behaviour:** This is the same logic moved over, and `deleteIfCaptureTemp` still returns true only when a file was deleted.
