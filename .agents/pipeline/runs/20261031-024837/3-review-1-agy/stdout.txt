### Findings

- **[Hard Blocker]** `SaveVisitCommand.kt#L50`, `L55`: Static check S68 (`check_r3m.py`) fails because it expects `"isPlausibleBloodPressure("` and `"isPlausibleWeightKg("`, but the code uses function references `?.let(::isPlausibleBloodPressure)` and `?.let(::isPlausibleWeightKg)`.
  > Line 50: `parseBloodPressure(bloodPressure)?.let(::isPlausibleBloodPressure) != true`
  > Line 55: `parseWeightKg(weight)?.let(::isPlausibleWeightKg) != true`
  > **Fix**: Replace with explicit invocation `parseBloodPressure(bloodPressure)?.let { isPlausibleBloodPressure(it) } != true`.

- **[Should-fix]** `VisitVitals.kt#L8`: `weightRegex` restricts the optional unit suffix `(?:\s*(?:kg|...))?` to the dot branch, causing `"68,5 kg"` to be rejected. `VisitVitalsTest.kt#L64` incorrectly asserted `assertNull(parseWeightKg("68,5 kg"))`.
  > Line 8: `private val weightRegex = Regex("""^(\d{1,4})(?:(?:\.(\d))?(?:\s*(?:kg|kilograms|kilogram))?|,(\d))$""", RegexOption.IGNORE_CASE)`
  > **Fix**: Use `^(\d{1,4})(?:[.,](\d))?(?:\s*(?:kg|kilograms|kilogram))?$` and update test.

- **[Nit]** `VisitEditor.kt#L217`, `L254`: Redundant check `if (bpLevel(draft.values.bloodPressure) != BpLevel.NORMAL)` wrapping `BpAlertLabel(draft.values.bloodPressure)`, which already guards against NORMAL internally.
  > Line 217: `if (bpLevel(draft.values.bloodPressure) != BpLevel.NORMAL) {`

- **[Nit]** `ClinicalBadges.kt#L167`: Calls `bpLevel(raw)` immediately after `bpAlertResource(raw)` already evaluated `bpLevel(raw)`, parsing the string twice.
  > Line 167: `val isSevere = bpLevel(raw) == BpLevel.SEVERE`
