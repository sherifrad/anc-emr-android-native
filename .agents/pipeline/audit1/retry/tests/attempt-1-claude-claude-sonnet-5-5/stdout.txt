### Three high-risk tests and a mutation that still passes them
1. **`AppLockPolicyTest`** pins `shouldLockOnReturn` only. Mutation: make `MainActivity` never call `recordBackgroundTime`, or call it in `onStart` instead of `onStop`. All 8 tests and S11 stay green (S11 only checks that the function name appears). The 10-minute lock (D6) can silently never fire.
2. **`VaultCleanupRuleTest` / S6 / S7.** Mutation: in `VaultFiles.cleanupUnpublishedArtifacts`, keep the call `hasVaultDatabase(` but negate it (`|| hasVaultDatabase`) or compute and ignore its result. S7 passes (substring check) and the unit test covers only the helper. Real clinic data could be deleted.
3. **`BackupVaultIntegrationAndZeroDataLossTest`.** Mutation: make `createEncryptedBackup` omit `addressText`, `dateOfBirth`, `obstetricNotes`, or all attachments. Compared fields are a short list, the DAO is a null proxy, and the test still passes. Same for `PinPolicyTest.matchesPbkdf2HmacSha256Vector`. It compares against the JCE call with the same inputs, so swapping the algorithm and the reference together would pass. There is no fixed known-answer vector.
