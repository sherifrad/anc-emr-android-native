The owner's sample (Mona Ragab) has no attention entries and a normal BP (110/70), so the entry texts below are the in-repo test fixtures from ClinicalAttentionUiTest: "Severe PIH" (Critical), "Anaemia" (Alert), "Prefers female doctor" (Note) and the severe BP 165/105 on 2026-11-10. They are fixtures, not patient facts. The empty state shows Mona's real state.

Design reasoning

Reading this as: the safety block a doctor must not miss, calm but unmistakable, dial ENERGY 1 / RHYTHM 1 / MOTION 1.

  • An entry reads like a field. Level word on top (12 sp bold, the "label"), the text below (16 sp, the "value"), in a tinted 10 dp box. The doctor learns one pattern for the whole record.
  • Level colours stay separate from field families. Critical keeps the scheme error colours with a 1.5 dp error border. Alert moves from the pale #FFFBEB with #B45309 text (4.84:1) to the amber Moderate tokens (#FCEFD6, #6E4708, 7.19:1), so amber means "concern" everywhere. Note is neutral (#EFE9E4).
  • The word carries the level. The warning and info icons go: "Critical", "Alert", "Note" already say it, and the icon repeated the colour. The level never depends on colour.
  • Order unchanged: severe BP first, then Critical, Alert, Note (sortedForDisplay).
  • Strip in the header uses the same two-line pattern: level word, then the text clamped to two lines, then "+N" and a mirrored chevron (it opens the dialog, so the chevron is an affordance, not decoration).
  • Title in sentence case: "Clinical attention" (string value change, no test asserts the old casing).
