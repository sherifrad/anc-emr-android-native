Mock S10: Plan tab and attachments

For slice 10. The Plan tab shows two cards: the delivery planning card (already redesigned in slice 2, unchanged here) and the documents and attachments section, which is the same component as on Overview. This slice restyles the attachments section, the add attachment dialog and the viewer's chrome. Patient: Mona Ragab (27+2 wks, G4 P1 A2, EDD 11/02/2027, Mothercare, 12000). Mona's sample has no attachments, so the two files are the in-repo fixture from DeleteUndoUiTest ("Scan 1" and "Scan 2", ultrasound, 1024 bytes each, captured 2026-03-01 and 2026-03-02, hash "00"). One viewer frame is layout only: a full 64-character hash shown as zeros to prove the wrap.

Design reasoning

Reading this as: a filing cabinet attached to the record, read often, added to now and then. Dial ENERGY 1 / RHYTHM 1 / MOTION 1.

  • Same section card as Overview. The attachments section becomes a RecordSectionCard, like the delivery card above it: navy 18 sp title, "Add" as a 48 dp word, white body. The tinted card, the info icon and the filled "+ Add" pill go.
  • Files as rows, not band cards. The section is one of the record's sections (on Overview too), so a band card per file would be a box inside a box. Rows split by hairlines, like lab tests in slice 8: the image itself on the left (56 dp, radius 10), the title 16 sp, then two grey 14 sp lines.
  • Dropped: the green shield on every row (it is drawn without any check, so it claims a verification that never ran), the 11 sp lines, the pink category pill, the "-" glyph in an empty thumbnail, the middle dots.
  • Filters use the patient list chip (RecordFilterChip, moved out of PatientListScreen): radius 10, selected chip navy. Forms keep today's M3 chips until the editor slices, so the dialog's chips stay as they are apart from text size.
  • Dialog: the two 120 dp icon tiles become two plain 64 dp buttons with the same words; the overlay pills on the preview ("Retake", "Gallery", 11 sp, no 48 dp target) move under the preview as text actions; Cancel and Save use the sheet button row (SheetCancelSaveRow).
  • Viewer: the decorative avatar icon goes; the medico-legal strip loses its tinted box and becomes four plain lines; the hash goes from 9 sp on one clipped line to 12 sp monospace that wraps.

6. Compose mapping

  1. PlanTab: same Column, spacedBy(12.dp) (was 14). DeliveryPlanningCard unchanged.
  2. AttachmentsSectionCard = RecordSectionCard(title = attachments_title, family = FieldFamilies.patient(), modifier.testTag("attachmentsSectionCard"), action = if not archived { SectionTextAction("Add", "Add attachment", onAddAttachment, Modifier.testTag("addAttachmentBtn")) }).
  3. Summary: Text(pluralStringResource(attachments_summary, n, n, size), RecordType.Secondary, onSurfaceVariant). Filters: FlowRow { RecordFilterChip(...) x5 }, same selectedFilter state.
  4. Row: Column { if (index > 0) HorizontalDivider(outlineVariant); Row(Modifier.fillMaxWidth().testTag("attachmentCard-$id").clickable(onClickLabel = attachment_open) { onViewAttachment(it) }.heightIn(min = 72.dp).padding(vertical = 8.dp), spacedBy(12.dp)) { thumbnail 56 dp clip(RecordShapes.Small); Column(weight 1) { title RecordType.KeyValue maxLines 2; two RecordType.Secondary lines } } }.
  5. Add dialog: Card(shape = RecordShapes.Large, elevation 0); header RecordType.SectionTitle onSurface plus name RecordType.Action onSurfaceVariant; labels FormFieldLabel (new, ui/components/FormFieldLabel.kt; onSurfaceVariant outside a family); two OutlinedButtons (64 dp) for the sources; preview actions SectionTextAction; buttons SheetCancelSaveRow.
  6. Viewer (level 3): Card(RecordShapes.Large); header name RecordType.CardName, line RecordType.Secondary; image box RecordShapes.Small; meta Column(spacedBy(4.dp)): StatusWord, two RecordType.Secondary lines, hash RecordType.Tag 12 sp monospace, no maxLines.

7. Decisions for the owner

  1. Failed integrity check wording. Today a missing or altered file shows "Protected Medical Vault", which reads as reassurance. Recommend "Integrity not verified" as an amber word. Copy change in a level-3 file.
  2. Files as rows inside the section, not one band card per file. Recommend rows (no box inside a box; the section also sits on Overview).
  3. Category names and the untitled title. "Ultrasound Scan", "Laboratory Investigation", "General Medical Attachment" are title case, and an untitled file reads "Ultrasound Scan · 2026-03-01". Recommend sentence case and ", " (touches AttachmentSyncManager.kt and level-3 ClinicalFormat.kt, and AttachmentDisplayTitleTest). Not in this mock.
