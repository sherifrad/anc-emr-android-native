Mock S17: Catalog settings

Covers ui/CatalogSettingsSections.kt (LabCatalogSettingsSection, MedicationCatalogSettingsSection, AddLabTestDialog, AddLabCategoryGroupDialog, AddMedicationDialog, and delete/reset confirmations). Hosted inside SecuritySettingsDialog.kt (Slice 18 chrome kept unchanged for context at its real ~298 dp inner width on 360 dp screens). Real sample data from ClinicalCatalogRepository: Haemoglobin (Hb), Fasting Blood Sugar (FBS), Hepatitis B Surface Antigen (HBsAg), CBC, Urine Routine & Microscopic, Paracetamol 500 mg, Folic Acid 5 mg, Labetalol 100 mg.

Design reasoning

Reading this as: clinic catalog configuration inside settings where doctors add, edit, search, and prune lab tests, diagnostic panels, and standard medications without crowding a 360 dp screen. Antislop dials: ENERGY 1 / RHYTHM 1 / MOTION 1 (pressed and focus states only, no new animation).

  • Background (sand) family for both labs and medications: matches LabsTab, LabEditor (Slice 16), and MedicationSheet (Slice 11) via FieldFamilies.background() (#F1EDE4 / #594A2C light, #36301F / #E0CFA6 dark), dropping 11 sp pink secondaryContainer chips and grey surfaceContainerLow slabs.
  • Give titles full width inside the 298 dp dialog column: moving the primary action (Add test, Create panel, Add medication) below the title and placing Edit/Delete 48 dp icon buttons beside the metadata row stops "My medication list" and "Hepatitis B Surface Antigen (HBsAg)" from wrapping into narrow columns.
  • Calm hierarchy for tests, panels, and medications: group individual tests and medications inside RecordSectionCard with crisp hairlines, and render lab panels as RecordBandCards with BandChip test counts and a quiet white PlainField test list (zero 20-pill boxes inside cards).
  • Accessible 48 dp dialogs that scroll safely: move the three Add/Edit forms to 16 dp white dialogs with fixed headers, scrollable bodies (fixing the missing scroll in AddLabTestDialog), external 12 sp FormFieldLabels, 48 dp RecordFilterChips (removing the 11 sp medication frequency chips), side-by-side Name and Dosage in AddMedicationDialog (stacking above 1.3x scale), and pinned SheetCancelSaveRow footers.
  • Clear states and honest destructive actions: add Clear search recovery actions on search-no-result states, Add/Reset recovery on empty states, and style Delete/Reset confirmations with error-colored destructive buttons like DiscardChangesDialog (Slice 11).

9. Compose mapping

  1. Background family scope: Wrap LabCatalogSettingsSection, MedicationCatalogSettingsSection, and the three form dialogs in CompositionLocalProvider(LocalFieldFamily provides FieldFamilies.background()).
  2. Section header & primary button: Text in RecordType.SectionTitle (primary, .semantics { heading() }) + RecordType.Secondary count summary, FlowRow of RecordFilterChip(..., wrap = true, minTouchTarget = true) for labIndividualTestsTab and labCategoryGroupsTab, and full-width Button(..., shape = RecordShapes.Small, modifier = Modifier.fillMaxWidth().minimumTouchTarget()) with RecordType.Action.
  3. Search field: OutlinedTextField with shape = RecordShapes.Small, textStyle = RecordType.FieldValue, colors = editorFieldColors(), leading Icons.Default.Search, and conditional 48 dp trailing Icons.Default.Close clear button.
  4. Individual tests & Medications list: RecordSectionCard(title = ..., family = bgFamily) containing rows split by HorizontalDivider(outlineVariant): full-width RecordType.CardName title above, FormFieldLabel + RecordType.Secondary metadata (using medicationFrequencyLabel(med.frequency) from ClinicalPresets.kt) on the left, and 48 dp minimumTouchTarget() Edit and Delete IconButtons on the right.
  5. Lab panels: RecordBandCard(title = group.name, family = bgFamily, subtitle = ..., chips = { BandChip(...) }, actions = { ... }) containing PlainField(label = stringResource(R.string.catalog_included_tests), value = group.testNames.joinToString(", ")).
  6. Empty & search-no-result states: OutlinedCard(shape = RecordShapes.Large, containerColor = surface, border = BorderStroke(1.dp, outlineVariant)) with RecordType.CardName title, RecordType.Secondary guidance, and 48 dp RecordShapes.Small recovery actions.
  7. Add/Edit dialogs: Shared CatalogFormDialog using Dialog(usePlatformDefaultWidth = false) + Surface(Modifier.fillMaxWidth(0.92f).heightIn(max = (screenHeightDp - 32).dp), shape = RecordShapes.Large, color = surface, border = BorderStroke(1.dp, outlineVariant)), pinned RecordType.SectionTitle header, verticalScroll body with FormFieldLabel + OutlinedTextField(editorFieldColors(), RecordShapes.Small) + RecordFilterChip(minTouchTarget = true, wrap = true), and pinned SheetCancelSaveRow footer.
  8. Delete & Reset confirmations: AlertDialog(shape = RecordShapes.Large, containerColor = surface) matching DiscardChangesDialog (Slice 11), with RecordType.SectionTitle title, RecordType.FieldValue text, and minimumTouchTarget() RecordShapes.Small TextButtons (Cancel in primary, Delete/Reset in error).

10. Decisions for the owner

  1. Form dialog container (Dialog with pinned header & SheetCancelSaveRow vs M3 AlertDialog): Today AddLabTestDialog has no scroll (clipping at 1.3x/2.0x) and M3 AlertDialog narrows inner content to ~264 dp on 360 dp phones. Recommended: use 0.92f-width Dialog (~331 dp, matching SecuritySettingsDialog) with scrollable body and pinned SheetCancelSaveRow for the three Add/Edit forms, while keeping the 5 short Delete/Reset confirmations as AlertDialog.
  2. PlainField test list inside RecordBandCard for Lab Panels: Replace up to 20 grey 11 sp pills inside each panel card with one clean PlainField inside RecordBandCard (per PLAN.md Section 8), keeping interactive RecordFilterChip multi-select chips inside AddLabCategoryGroupDialog. Recommended: accept.
  3. Full-width primary action button and compact switcher labels: Place Add test / Create panel / Add medication as a full-width 48 dp button below the title and shorten "Panels & Profiles (7)" to "Panels (7)" inside a wrapping FlowRow so nothing crushes at 298 dp inside SecuritySettingsDialog. Recommended: accept.
  4. RecordSectionCard hairline rows with full-width titles for Individual tests and Medications: Replace 12 dp grey cards and side-cramped names with RecordSectionCard rows giving titles full width above metadata + 48 dp Edit/Delete icons. Recommended: accept.
  5. Recovery actions on empty/no-result states and red destructive Delete/Reset buttons: Add Clear search / Add / Reset to defaults recovery buttons on empty and no-result states, color Delete/Reset in error, normalize create_diagnostic_panel to sentence case, replace middle dots with commas, and move all hardcoded UI text to strings.xml. Recommended: accept.
