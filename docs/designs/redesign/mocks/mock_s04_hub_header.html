Mock S04: Patient hub header and tab bar

For slice 4. Sample: Mona Ragab, منى رجب, G4 P1 A2, A+, BP 110/70 (not raised, so no BP chip). The expanded header prints GA through the app's own formatter (calculateGestationalAge(), "27w 2d"); the sticky bar and the list card use shortWeeksText ("27+2 wks"). Mona is shown as Moderate risk so the risk tag is visible. She has no attention entries and no recorded allergy, so those appear only in the layout-only frame with bracketed placeholders.

Design reasoning

Reading this as: the always-visible identity block of a patient record, dial ENERGY 1 / RHYTHM 1 / MOTION 1 (the existing collapse animation is kept, nothing new moves).

  • Facts as a metric row, not a rainbow of pills. Today GA is sky blue, parity purple, blood group blue, age indigo, risk red. After: GA, Parity, Blood group (and Age when recorded) use the list card's metric cell: 12 sp label, 16 sp value. Same entity, same component as the patient card.
  • Status as words in tags. Risk uses StatusTag. Normal risk shows a neutral "Normal risk" tag here (the header is the full record; the list hides it). Recorded allergy stays a red alert tag with its text, "No known drug allergies" a neutral tag.
  • Rh negative stops being colour only. Today an Rh-negative blood group is only tinted rose. After, the cell adds a High-tone "Rh negative" tag.
  • Name 22 sp bold (was 20 sp extra bold), wraps, never cut (a test checks up to four lines at font scale 2).
  • Tabs: words only. The six tab icons repeat the words and cost width on a 360 dp scrolling row. Count badges use the 10 dp radius (was a 999 dp pill). An alert without a count was a 6 dp rose dot (colour only); it becomes a High-tone "!" tag with the label "needs attention". Labs keeps "N▲" for abnormal results.
  • Kept as they are: the collapse behaviour, the sticky bar at 56 dp, the action icons (back, attention, report, edit: each is a real action with a label), all tags.
