Mock S09 v2: three options for the Meds tab

The owner found mock D's box-per-field too heavy for medications and the flat revision too plain. This page shows three middle options, each with the same four medications, the tap-to-add row and the stop (undo) bar. Data: in-repo DemoFixtures medications, labelled as fixtures: Iron Polymaltose Complex 100 mg (Active), Calcium + Vitamin D3 500 mg / 400 IU twice daily (Active, flagged non-compliant, side effect "Reports constipation and stomach discomfort"), Folic Acid 5 mg (Completed). No fixture is Discontinued, so Paracetamol 500 mg, as needed (PRN), is shown with that status to demonstrate it. Mona Ragab's own record has no medications.

What all three share

  • One container per unit, never a box inside a box. A card may have a tinted region of its own (a header band or a side token that reaches the card's edges), but no inner bordered box per field.
  • Status is a filled word chip: Active (blue), Completed (grey), Discontinued (outlined grey), Patient non-compliant (red). Word plus colour, never colour alone.
  • Medications use the Background family (sand) from the system, so the tab has its own identity next to Visits (blue) and Scans (teal).
  • Fast use: Stop is a visible red outlined button on every active drug (one tap, 48 dp); Edit is a word, Delete an icon button; tap-to-add is one 48 dp row; the stop bar is one dark 48 dp line with Undo.
  • Dial ENERGY 2 / RHYTHM 1 / MOTION 1 for this tab: a little more colour than the flat list, still calm. No gradients, glow, tracked caps, decorative icons or em dashes.

Option A. One card per medication

Each drug is one card. Its sand header band carries the status chip, the name and dose, and the start date; the white body carries route and frequency, a warning line when needed, and the actions. Past drugs get a grey band, so active ones stand out by colour and word.

Option B. Grouped by status

Three group cards: Active, Completed, Discontinued, each with a coloured header and a count. Inside, compact rows split by hairlines: name and dose, then route and frequency, with Stop at the end of active rows. The group says the status; only "Patient non-compliant" needs its own chip.

Option C. Dose-forward

Each card leads with a sand side token holding the dose in 20 sp bold and the frequency under it; name, route, status chip and actions sit beside it. The eye lands on "how much, how often" first.

Compose mapping

  1. Status chip (all options): new MedStatusChip(status, nonCompliant): Surface(shape = RecordShapes.Small, color, border) with Text(RecordType.Tag.copy(Bold), padding(horizontal = 10.dp, vertical = 2.dp)); Active FieldPatientBg / FieldPatientLabel, Completed surfaceContainerHigh / onSurfaceVariant, Discontinued surface + StatusIncompleteBorder + onSurfaceVariant, non-compliant StatusHigh*. Dark tokens likewise. Tag medicationStatusBadge.
  2. Stop: the existing StopControl (tags stopMedication-, stopMedicationLabel-) drawn as OutlinedButton(shape = RecordShapes.Small, border = BorderStroke(1.5.dp, error), Modifier.heightIn(min = 48.dp)) with the word "Stop", no icon.
  3. Option A: OutlinedCard(shape = RecordShapes.Large); band Column(Modifier.fillMaxWidth().background(FieldBackgroundBg or surfaceContainerHigh for past).padding(12.dp, 10.dp, 12.dp, 8.dp)) with chip row and buildAnnotatedString name (Bold) + dose; body Column(padding(start = 12.dp, end = 4.dp)): route and frequency RecordType.Secondary, adverse line in StatusHighText, actions Row (Stop start, Delete and Edit end).
  4. Option B: per status one OutlinedCard; header Row(heightIn(min = 48.dp).background(tone)) title and count; rows separated by HorizontalDivider; Stop at row end; tap a row to open details with Edit and Delete. Grouping uses effectiveMedicationStatus, no new rule.
  5. Option C: OutlinedCard(Row(Modifier.height(IntrinsicSize.Min))); token Column(Modifier.width(96.dp).fillMaxHeight().background(FieldBackgroundBg)) with dose 20 sp Bold and frequency 12 sp SemiBold FieldBackgroundLabel; right column name, route, chip, actions.
  6. Tap-to-add and undo bar identical in all three: toggle row 48 dp outlined, tiles Surface(shape = RecordShapes.Small, color = FieldBackgroundBg) 56 dp in a 2-column grid, undo Surface(color = onSurface) with surface text (16.92 light, 12.64 dark; the theme sets no inverseSurface) one 48 dp line with TextButton Undo. Every existing tag kept.
