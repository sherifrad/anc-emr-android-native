### Decisions for the owner to confirm

1. **Form dialog container (`Dialog` with pinned header & `SheetCancelSaveRow` vs M3 `AlertDialog`)**: Today `AddLabTestDialog` has no vertical scroll and M3 `AlertDialog` narrows inner content to ~264 dp on 360 dp phones. **Recommended**: use `0.92f`-width `Dialog` (`~331 dp`, `RecordShapes.Large`) with scrollable body and pinned `SheetCancelSaveRow` for the three Add/Edit forms, while keeping the 5 short Delete/Reset confirmations as `AlertDialog`.
2. **`PlainField` test list inside `RecordBandCard` for Lab Panels**: Replace up to 20 `11 sp` grey pills inside each panel card with one `PlainField("Included tests", ...)` inside `RecordBandCard` (per [PLAN.md](file:///Users/sherifgamalradwan/anc-emr-android-native/docs/designs/redesign/PLAN.md) section 8), keeping interactive `RecordFilterChip` test chips inside `AddLabCategoryGroupDialog`. **Recommended**: accept.
3. **Full-width primary CTA and compact switcher labels**: Place `Add test`, `Create panel`, and `Add medication` full width below the header (`48 dp`, no decorative `+` icon) and use `Individual tests (%1$d)` / `Panels (%1$d)` in a wrapping `FlowRow` so nothing squeezes inside `SecuritySettingsDialog`'s ~298 dp column. **Recommended**: accept.
4. **`RecordSectionCard` hairline rows with full-width titles for Individual tests and Medications**: Group tests and medications into `RecordSectionCard` hairline rows with full-width `16 sp` titles above metadata and `48 dp` Edit/Delete buttons instead of `12 dp` grey cards with side-cramped names. **Recommended**: accept.
5. **Recovery actions on empty/no-result states, red destructive buttons, and string normalization**: Add `Clear search` / `Add` / `Reset to defaults` recovery actions, color `Delete` and `Reset` in `error`, normalize `create_diagnostic_panel` to `"Create diagnostic panel"`, replace `"·"` middle dots with `", "`, and move all hardcoded UI text in [CatalogSettingsSections.kt](file:///Users/sherifgamalradwan/anc-emr-android-native/app/src/main/java/com/sherifradwan/ancnative/ui/CatalogSettingsSections.kt) into `strings.xml`. **Recommended**: accept.
