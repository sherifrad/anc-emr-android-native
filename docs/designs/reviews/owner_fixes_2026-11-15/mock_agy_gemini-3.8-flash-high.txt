1. **One Calm Tint Family Per Clinical Domain**: Rather than using rainbow hues across fields, each overview section uses a single restrained color family (e.g., slate navy `#F0F4FA` for medical history) with labels at 7.8:1 contrast and values at 16px inside tinted rounded boxes.
2. **Strict Two-Token Corner Radius**: Applied exactly two radius tokens across the entire interface (6px for chips, field boxes, and banners; 12px for cards, sections, and device containers) to eliminate visual noise.
3. **Dead Space Eradication in Directory Cards**: Integrated patient name and clinical status tags into a single flex row, reclaiming 28px of vertical dead space per card while keeping the 48px touch target for the action menu.
4. **Natural RTL Ergonomics for Arabic Names**: Structured the compact header with directional flex groups so Arabic names and status tags flow right-to-left without clipping or unanchored tags on narrow 360dp viewports.
5. **Multi-Attribute Clinical Safety**: Adhered strictly to medical UX rules by never indicating risk or incomplete states by color alone, pairing every status chip with explicit wording and structured 3-column micro-metrics.
