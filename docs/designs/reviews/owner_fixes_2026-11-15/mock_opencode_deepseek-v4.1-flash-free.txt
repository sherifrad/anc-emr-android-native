<b>1. Three tiers, not two.</b> Heading is 15/700 in ink, field label is 12.5/600 in the family hue, value is 16/600 in navy ink inside a tinted 48 dp box, so the eye can sort structure before reading words.

<b>2. One tint per field family, not per field.</b> Five muted families: identity slate, dating blue, obstetric carries both obstetric history and previous pregnancies, medical sand, medications plum. Tints stay near neutral and labels run 8.5:1 or better, so it reads as grouping rather than a rainbow.

<b>3. The tag becomes part of the name row.</b> It sits beside the name at the same baseline with a fixed pill width, which removes the 48 dp dead band and holds the card near 150 dp including the menu target.

<b>4. RTL is structural, not alignment hacks.</b> The Arabic card uses dir="rtl" so grid order mirrors, with numerals wrapped LTR so BP and EDD cannot flip, and Arabic metric labels get a taller line box so descenders are not clipped.

<b>5. The Overview grows taller by design.</b> Label above box costs vertical space on a detail screen that already scrolls, while the list card gets shorter where scan speed matters; risk and completeness always carry a word, never colour alone.
