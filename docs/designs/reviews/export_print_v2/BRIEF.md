# Export v2: print, preview and share (owner request 2026-11-14, to run AFTER the four owner fixes are merged)

Owner words: the PDF export is not optimised for printing; tables are scrollable and the page is crowded; study the current design, delegate to other models to find the best one; clicking Print crashes the app; clicking Share gives one long plain text.

## Facts found (orchestrator, read-only, 2026-11-14)
1. PRINT CRASH, root cause proven from the phone's crash log (QA copy `com.sherifradwan.anc.qa`, 2026-11-14 16:24):
   `java.lang.IllegalStateException: Can print only from an activity` at `android.print.PrintManager.print`, called from `PatientPrintManager$printPatientReport$1.onPageFinished` (`ui/report/PatientPrintManager.kt:40`). The dialog passes `LocalContext.current` from inside a Compose Dialog, which is a wrapper, not the Activity; `PrintManager` rejects it. Fix direction: unwrap the `ContextWrapper` chain to the real `Activity` before `getSystemService(PRINT_SERVICE)` and before creating the print WebView; do nothing (show a message) when no Activity is found; keep a strong reference to the WebView until the print job has been handed over; the job name must not contain characters that are illegal in file names (patient names contain spaces and Arabic). This was never caught because no test prints through a real Activity.
2. SCROLLABLE TABLES: every table sits in `.table-scroll { overflow-x: auto }` plus a screen `@media (max-width: 540px)` block with `min-width` on tables. That is right for a phone preview but wrong for a page that must read like paper. The preview on a 360 dp screen should be a scaled whole-page view (pinch to zoom), not a horizontally scrolling table.
3. CROWDED PAGE: 12 visits, 7 scans, 10 labs and every medication on two A4 sheets in 7 to 8 pt text, five to seven columns per table, many boxed sections.
4. SHARE: `ClinicalSummaryGenerator`/`patientShareText` returns one long text sent with `ACTION_SEND` text/plain. A hospital or a patient cannot read it well.

Judge them against: readable at 9 pt on A4, a long record paginates cleanly, nothing scrolls, works at 360 dp preview as a whole page, 4.5:1 contrast, one canonical row rule from `ReportSections.kt`. Argon scores the three mocks blind (without author names); the owner picks one before any Kotlin is written (mock approval is the owner's call).
