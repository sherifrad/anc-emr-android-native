ORACLE-A (print paging; a long record must never be clipped). In the `@media print` block `.page-sheet` loses `height`, `max-height` and `overflow: hidden` (keep `min-height: 297mm`, width, padding). Because content may now run onto further sheets, fixed sheet numbers are removed: delete the header row `Page:` `1`, the page 2 badge text becomes `CONTINUED`, and both footers lose their `<span>Page 1</span>` / `<span>Page 2</span>` (footer keeps one span). ORACLE-C (delivered patient). In the `ga-highlight` box a delivered patient gets `escapeHtml(patient.deliveryOutcomeLine())` only; the words "Archived record" appear only in the `status-banner`.
ORACLE-D (one rule for the delivery rows). The HTML "Delivery Plan" section prints exactly these rows (label followed by ":") with `eddText = datingSummary.edd?.let(::formatDmy)`; the share text prints the same rows under `DELIVERY PLAN` (block left out when the list is empty), getting the EDD the same way from `datingSummaryOf(patient, asOf)`. The four inline row templates in the HTML are replaced by one loop. Keep the bold navy style for the "Delivery Outcome" and "Estimated due date" values if simple; otherwise all rows use `<span class="v">`.

Example: `birthMethod = ""`, `deliveryBy = "CS"`, `pregnancyType = "Singleton"` prints `Singleton · CS`; `outcome = "LiveBirth"`, `outcomeText = ""` prints `Live Birth`.
