## Checked and found correct

- **HTML escaping**: every user-entered string that reaches the markup is wrapped in `escapeHtml` — displayName, caseId, dates, BP, weight, findings/notes, scan fields, lab testName/result/unit/range, med name and instructions, prev-preg outcome/method/place/dateText, appendix photo labels, even the `<title>`. The only raw injections (`vGa` L104, `printDateStr`, `totalPages`, base64 logo, the CSS alert constants) are internally derived, not patient-typed. No user-controlled unescaped output found in the visible code.
- **Hidden-row arithmetic**: `take(N)` → hidden = `size − N` is consistent in all four tables, negative counts are suppressed by the `hidden <= 0` guard, and there is no off-by-one when the list exactly equals the limit.
- **Colspans**: 6 (visits), 7 (scans), 4 (labs), 2 (meds) all match their tables — including the empty-state rows and the "more" rows.
- **Labs cap direction**: `sortedByDescending` keeps the **newest** 10 — the correct end survives, unlike visits/scans.
- **Abnormal labs**: abnormal results get distinct styling plus an explicit "(Abnormal)" suffix; a missing unit degrades harmlessly to a trailing space.
- **EFW already-unit values** ("kg", "gm", "grams") pass through unchanged; null → "-".
- **Per-visit GA** is computed from each visit's own date, not today's GA — historical rows stay historically accurate (even for delivered patients).
- **BP CSS escalation** is computed from the *displayed* rows only, so the styling matches what's actually printed.
- **Previous-pregnancy outcome labels**: the recorded `outcomeText` is preferred over canned labels; loss/stillbirth/termination all get the red badge; the method fallback chain (birthMethod → deliveryBy → lossManagement → terminationMethod) is sensible.
- **Empty states**: all five sections have a proper empty-state row/message with correct colspan, and the meds empty message matches a genuinely empty list.
- **Logo handling**: decode failure degrades to a text fallback without crashing, and the watermark is omitted when no logo exists.
- **Dating matrix**: null values fall back to "Not recorded", the EDD is visually flagged, and the discordance line is optional.
- **G/P/A** fall back to "-" when null.
- **Meds hidden-count** is arithmetically consistent even though the list itself is unsorted.
