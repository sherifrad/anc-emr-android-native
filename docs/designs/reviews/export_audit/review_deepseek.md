## Checked and found correct

- **Escaping of patient strings inside the template.** Every free-text patient field that appears in lines 1–286 is wrapped in `escapeHtml`: `displayName` (32, 157), `caseId` (23, 33, 158), `phone` (34), `bloodGroupText` (43), `allergyHistory` (84), `medicalHistory` (88), `surgicalHistory` (92), the delivery outcome line (240), the plan text (244), the formatted EDD (248). `pastDeliverySummary` (80) is the single exception, listed above.
- **Null handling for risk.** L49–50 handles null/blank explicitly as "Risk not recorded" instead of silently claiming normal — the right instinct, which makes defect #1 a bug in the branch, not in the design.
- **Rh-negative escalation.** The one place a safety-critical value is visually escalated both ways: red `text-rose` on the value (42) and a second `badge-danger` "Rh- Negative" (44). The English is wrong (#20) but the behaviour is right.
- **Missing-value convention.** "Not recorded" is used consistently on the history rows and on the plan/EDD rows (84, 88, 92, 244, 248). Only phone and blood group break it (#18, #19).
- **Delivery outcome row is genuinely conditional** (`deliveryOutcomeLine()?.let { … }.orEmpty()`), so a non-delivered patient does not get a dangling "Delivery Outcome:" label.
- **GPA row** prints gravida, parity and abortion numerically plus a delivery summary, matching the three stored counters — no derivation or guessing.
- **Section order is clinically sane**: identity → dating → history → previous pregnancies → visits (page 1), then ultrasound → labs → medications → plan → attestation (page 2). Nothing clinical is buried after the signature.
- **No fixed pixel column widths.** Every `th` uses percentages inside a `.table-scroll` container, so both A4 and a 360 dp preview reflow rather than clip — this is the one structural thing consistently done right across all five tables.
- **Both sheets re-identify the patient** (name + ID on 157–158, ID again at 23/33). A photocopied or faxed page 2 is still attributable to a person.
- **Both footers carry clinic + clinician title** (134, 274–275), and page 2 adds a contact number.
- **Print date is on both sheets** (24, 159), so the record is time-stamped.
- **No `!!` non-null assertions** anywhere in the template — every nullable goes through `?:` or `?.let`.
